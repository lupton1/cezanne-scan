Frame

Drag on the prescan to mark a frame. Each frame keeps its own settings.

Workflow from Cezanne owners:

  1. Prescan, then draw a frame around each image.
  2. For negatives use flipped densities: HD high, SD low.
  3. Use the droppers: highlight on the brightest part of the image, shadow on the film rebate.
  4. Keep MIN 0 and MAX 255, sharpening off, add a gentle S curve.
  5. Scan all frames in one go. The files download to this computer.
